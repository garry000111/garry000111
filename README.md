I'm **Gaurav Khambat**, a **Backend Engineering** and **AI** enthusiast currently pursuing a **B.Tech in Computer Science & Engineering** at **IIIT Nagpur**.

I enjoy designing **scalable backend systems**, building **production-ready REST APIs**, and solving real-world engineering problems through clean architecture and efficient software design.
